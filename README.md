- AI-powered document generation
- AI-generated presentation workflows

### 🔥 Key Engineering Areas

* Autonomous browser-based web monitoring
* Playwright-powered web automation
* Competitor hotel price monitoring

* Campaign and partner-page monitoring
* Snapshot-based change detection
* ADDED / REMOVED / MODIFIED classification
* AI-generated insights
* Confidence scoring
* Severity scoring
* Human approval before sensitive execution
* Role-Based Access Control
* Audit logging
* Scheduled monitoring tasks
* REST API architecture
